소개

ClipSlicer 는 긴 영상에서 필요한 부분만 잘라 각각 저장하는 데 집중한 프로그램입니다. 편집 프로그램처럼 In 점·Out 점을 잡는 대신, 영상을 보다가 "여기서 자르자" 하는 지점에 가위 표시(마커)만 찍습니다. 마커 사이사이가 자동으로 구간이 되고, 필요 없는 구간은 끄고, 나머지를 한 번에 내보냅니다.

이런 일에 맞습니다 — 방송·강의 녹화를 주제별로 나누기, 긴 촬영본에서 쓸 부분만 추리기, 광고·잡담 빼고 한 편으로 합치기, 영상에서 소리만 뽑기. 자막·효과·여러 트랙 편집은 다른 프로그램의 영역입니다.

5분 안에 시작하기

  1. 영상 열기. 창 아무 곳에나 파일을 끌어다 놓거나 Ctrl+O. 여러 파일, 폴더째도 됩니다. 왼쪽 목록에 쌓이며 각 영상은 자기만의 마커를 가집니다. 열자마자 뒤에서 썸네일·파형·키프레임을 분석하므로 몇 초 뒤 타임라인이 채워집니다.
  2. 재생하며 자를 곳 찾기. Space 재생/정지. 타임라인에 마우스를 올리면 그 위치의 썸네일이 떠서 훑어보기 쉽습니다. 멈춘 뒤 ← → 로 한 프레임씩, Shift/Ctrl 조합으로 1초/10초씩 이동합니다. R 을 누르면 현재 위치 앞뒤 2초를 반복 재생해서 자를 지점이 맞는지 확인할 수 있습니다.
  3. 마커 찍기. S 또는 빨간 ✂ 여기서 자르기 버튼. 빨간 세로선이 생기고 타임라인이 색 구간으로 나뉩니다. 잘못 찍었으면 Ctrl+Z.
  4. 구간 정리. 필요 없는 구간은 타임라인에서 Ctrl+클릭 (또는 E, 또는 오른쪽 목록 체크 해제). 꺼진 구간은 어둡게 표시됩니다. 오른쪽 목록의 파일명 칸을 더블클릭하면 이름을 직접 정할 수 있습니다.
  5. 내보내기. Ctrl+E. 켜진 구간이 각각 파일로 저장됩니다. 기본 위치는 원본 옆 원본이름_cuts 폴더이고, 끝나면 폴더가 열립니다. 방식은 빠르게가 기본값이며, 재인코딩 없이 원본을 그대로 끊어 내므로 수 초 안에 끝납니다.

왼쪽 — 영상 목록열린 영상들. 이름 옆 [3] 은 켜진 구간 수. 클릭해서 전환, Ctrl+↑ Ctrl+↓ 로도 이동. 전환해도 각 영상의 마커·재생 위치는 유지됩니다.

오른쪽 아래 — 내보내기출력 폴더, 모드, 출력 종류(영상/오디오/세로), 합치기, 음량 정규화, 캡션·자막, 유튜브·디스코드 전송, 진행률과 로그. 오른쪽 패널 전체를 Ctrl+Shift+R 로 접을 수 있습니다.

확대해서 정확히 찍기

한 시간짜리 영상은 타임라인 1픽셀이 3초쯤 됩니다. Ctrl+휠로 마우스 위치를 중심으로 확대하세요. 확대되면 아래에 스크롤바가 나타나고, 휠만 굴리면 좌우로 이동합니다. 재생 중 플레이헤드가 화면 밖으로 나가면 자동으로 따라갑니다. 상태 표시줄에 현재 배율이 보이고, Ctrl+0 으로 전체 보기로 돌아옵니다.

썸네일 미리보기

마우스를 올리거나 드래그하는 동안 그 위치의 썸네일과 시각이 팝업으로 뜹니다. 플레이어가 따라오기 전에 장면을 미리 보는 용도입니다. 영상 길이에 따라 1초~수 초 간격으로 뽑은 썸네일이라 정확한 프레임은 플레이어에서 확인하세요.

시간 직접 입력

컨트롤 줄의 시간 표시를 클릭하면 입력란이 됩니다. 1:23.5 01:02:03 83.5 1h2m3s 어느 형식이든 쓰고 Enter.

마커와 구간

마커는 영상 안의 한 시각입니다. 마커가 n개면 구간은 n+1개이고, 첫 구간은 0초부터, 마지막 구간은 영상 끝까지입니다. 마커끼리 0.05초보다 가까우면 추가되지 않습니다. 마커는 프레임 경계에 맞춰 찍힙니다.

클립 모드 (I / O)

긴 영상을 "나누는" 게 아니라 쓸 부분만 "뽑을" 때는 클립 모드가 빠릅니다. 재생하다가 시작 지점에서 I, 끝 지점에서 O. 타임라인에 초록 점선으로 시작점이 표시되고, O 를 누르는 순간 양쪽에 마커가 찍히면서 그 사이만 켜지고 나머지는 전부 꺼집니다. 반복하면 클립이 쌓이고, 내보내기에서 하나로 합치기를 켜면 하이라이트 모음 한 편이 됩니다. Esc 로 찍다 만 시작점을 취소합니다.

▒▒▒▒▒▒▒▒▼████ 클립 1 ████▼▒▒▒▒▒▒▒▒▒▒▒▒▼███ 클립 2 ███▼▒▒▒▒ (꺼짐) I ───── O (꺼짐) I ──── O (꺼짐)

클립 모드로 만든 구간도 보통 구간과 똑같이 다룰 수 있습니다 (끄기, 이름, 마커 이동, 실행 취소). 클립 목록은 작업 파일에 저장됩니다.

자르기 모드

빠르게 (기본)

원본 스트림을 그대로 복사(-c copy). 수 초 안에 끝나고 화질 손실이 전혀 없습니다. 대신 키프레임에서만 시작할 수 있어 시작점이 앞으로 당겨집니다(보통 1~2초, 화면 녹화는 더 길 수도). 끝점은 정확합니다.

스마트

시작점부터 다음 키프레임까지만 재인코딩하고 나머지는 복사한 뒤 이어 붙입니다. 빠르면서 프레임 단위로 정확하고, 재인코딩되는 부분은 1~2초뿐이라 화질 손실도 거의 없습니다. H.264 / HEVC 영상에서 동작하며 아니면 자동으로 "정확하게"로 넘어갑니다.

정확하게

구간 전체를 H.264 CRF 18 로 재인코딩합니다. 가장 느리지만 어떤 영상이든, 어떤 플레이어에서든 문제없습니다. GPU 인코더가 있으면 훨씬 빨라집니다. 출력은 항상 mp4.

어떤 걸 고를까

대부분 빠르게. 시작점이 1~2초 앞으로 밀리는 게 싫으면 스마트 (파일을 한 번 더 읽으니 그만큼 시간이 듭니다). 스마트 결과가 특정 플레이어에서 이상하거나, 특이한 코덱(VP9, AV1, ProRes 등)이면 정확하게. 내보내기 로그에 각 파일이 실제로 어떤 방식으로 처리됐는지(복사 / 스마트 / 재인코딩) 표시됩니다.

키프레임 이야기

압축된 영상은 모든 프레임을 온전한 그림으로 저장하지 않습니다. 몇 초마다 한 장(키프레임, I-프레임)만 온전히 저장하고, 그 사이 프레임들은 "앞 그림에서 바뀐 부분"만 저장합니다. 그래서 중간 프레임은 앞 키프레임부터 차례로 풀어야만 그려집니다.

키프레임: K·····K·····K·····K····· 자르고 싶은 곳: │ 빠르게 모드 결과: K═════│═══════════ ← 앞 키프레임부터 (앞에 여분이 붙음) 스마트 모드 결과: ▓▓▓K═══════════ ← ▓ 부분만 새로 인코딩, 나머지 복사 정확하게 결과: ▓▓▓▓▓▓▓▓▓▓▓▓▓▓ ← 전부 새로 인코딩

키프레임 간격은 인코더 설정에 따라 다릅니다. 유튜브 다운로드·카메라 영상은 1~2초, OBS 기본값은 2초, 화면 녹화 프로그램 중에는 5~10초인 것도 있습니다. 타임라인 눈금 아래 흰 점이 키프레임이고, 영상을 열 때 상태 표시줄에 "키프레임 N개, 평균 간격 x초"가 잠깐 표시됩니다.

설정 ▸ 마커를 키프레임에 맞추기를 켜면, 마커를 찍거나 옮길 때 0.5초 안에 키프레임이 있으면 거기에 달라붙습니다. 이러면 "빠르게" 모드로도 정확하게 잘립니다. 키프레임 간격이 짧은 영상에서 유용합니다.

폴더비워 두면 각 원본 옆 원본이름_cuts. 지정하면 모든 영상의 결과가 그 한 곳에 모입니다.
모드빠르게 / 스마트 / 정확하게. 위 항목 참고.
출력영상+오디오 / 영상만 (소리 없음) / 오디오만 (m4a) / 오디오만 (mp3) / 세로 9:16 쇼츠. 세로일 때는 레이아웃(크롭 / 블러 배경)을 고릅니다.
하나로 합치기켜진 구간들을 순서대로 이어 붙여 파일 하나(원본이름_merged)로. 순서는 목록의 ▲▼ 로 바꿉니다.
완료 후 폴더 열기끝나면 탐색기로 출력 폴더를 엽니다.
완료 후 유튜브에 올리기 · 디스코드로 보내기끝나면 올리기 창을 열거나 디스코드 웹훅으로 파일을 보냅니다 (유튜브 · 디스코드).
음량 정규화소리 크기를 -14 LUFS 로 고르게. 오디오만 다시 인코딩 (출력 효과).
캡션 · 자막영상에 굽는 글자와 자막 파일. 있으면 재인코딩됩니다 (출력 효과).
현재 영상 / 모든 영상선택된 영상만, 또는 목록 전체를 한 번에. 전체는 큐로 순서대로 처리되고 진행률에 [3/12] 처럼 표시됩니다.
취소진행 중인 ffmpeg 를 멈추고 만들다 만 파일을 지웁니다.

파일 이름

기본 규칙은 {name}_{n} → 방송녹화_01.mp4. 설정 ▸ 파일명 규칙에서 바꿀 수 있습니다.

자리표시자뜻예
{name}원본 파일 이름방송녹화
{n}구간 번호 (두 자리)03

예: {name}_{start}-{end} → 방송녹화_12m05s-15m40s.mp4. 구간 목록에서 직접 입력한 이름이 항상 우선합니다. 확장자는 모드에 따라 정해집니다 (빠르게·스마트는 원본과 같게, 정확하게·세로·캡션/자막/워터마크는 mp4, 오디오는 m4a/mp3).

같은 이름의 파일이 있으면

내보내기 전에 목록을 보여 주고 덮어쓰기 / 번호 붙여 저장 (이름_1.mp4) / 취소 중 고릅니다.

GPU 인코딩

시작할 때 NVIDIA NVENC → Intel QSV → AMD AMF 순으로 인코더를 시험해 보고, 되는 것을 상태 표시줄에 표시합니다. 설정 ▸ GPU 인코딩 사용이 켜져 있으면 "정확하게"와 "스마트"의 재인코딩에 사용해 5~10배 빨라집니다. 같은 용량에서의 화질은 CPU(libx264)가 조금 더 좋으니, 화질이 최우선이면 끄세요.

무음 자동 마커

편집 ▸ 무음 구간에 자동 마커 (Ctrl+Shift+M, 또는 구간 목록 위 버튼). 오디오를 훑어서 기준 음량보다 작은 상태가 최소 길이 이상 이어지는 곳을 찾습니다.

설정설명
무음 기준 음량기본 -35 dB. 이보다 작으면 무음. 잡음 섞인 녹음은 -25 dB 쯤으로 올리고, 깨끗한 녹음은 -45 dB 까지 내려도 됩니다.
최소 무음 길이기본 1초. 짧은 숨 고르기까지 잡고 싶으면 0.5초, 큰 단락만 원하면 3초 이상.
가운데에 마커 1개무음 한가운데서 깔끔하게 나눕니다. 강의를 주제별로 나눌 때.
양쪽 끝에 마커 2개 + 무음 구간 끄기무음 자체가 꺼진 구간이 됩니다. 하나로 합치기와 같이 쓰면 "무음 제거 영상"이 됩니다.

결과는 상태 표시줄에 "무음 구간 N개를 찾아 마커 M개 추가"로 표시되고, 마음에 안 들면 Ctrl+Z 한 번으로 전부 되돌아갑니다.

장면 전환 자동 마커

편집 ▸ 장면 전환에 자동 마커 (Ctrl+Shift+S). 화면이 크게 바뀌는 지점(컷, 화면 전환)을 찾습니다. 영상 전체를 작은 해상도로 훑어서 1시간 영상에 1~3분 정도 걸리고, 진행률이 내보내기 패널에 표시됩니다. 민감도(0~1)는 낮을수록 작은 변화도 잡습니다. 0.3~0.5 권장.

타임스탬프 붙여넣기

편집 ▸ 타임스탬프 붙여넣기 (Ctrl+Shift+V). 유튜브 챕터·댓글 타임라인 같은 텍스트에서 12:34 1:02:03 0:45.5 를 모두 찾아 마커로. 클립보드가 자동으로 채워집니다.

합치기 · 오디오 · 쇼츠

켜진 구간을 하나로 합치기

내보내기 패널의 하나로 합치기를 켜면 켜진 구간들을 각각 저장하는 대신 순서대로 이어 붙여 원본이름_merged 하나로 만듭니다. 각 조각을 선택한 모드로 자른 뒤 재인코딩 없이 이어 붙이기 때문에 빠릅니다. "광고 빼고 한 편으로", "무음 제거" 용도입니다. 이어 붙일 순서는 구간 목록의 순서 칸(▲▼)으로 바꿀 수 있습니다 (합치기 순서).

오디오만 추출

출력을 "오디오만 (m4a)" 또는 "(mp3)" 로 바꾸면 영상 없이 소리만 저장합니다. m4a 는 원본이 AAC 면 무손실 복사, 아니면 AAC 192 kbps 로 변환. mp3 는 항상 LAME 고음질(VBR 2)로 변환합니다. 합치기와 같이 쓸 수 있습니다.

영상만 (소리 없음)

출력을 "영상만 (소리 없음)" 으로 바꾸면 소리를 뺀 영상만 저장합니다. 고른 방식·합치기·캡션은 그대로 적용되고 마지막에 오디오만 빼므로 화질 손실이 없습니다.

세로 9:16 쇼츠 출력

출력을 "세로 9:16 쇼츠 (재인코딩)" 로 바꾸면 각 구간이 1080×1920 세로 영상으로 나옵니다. 레이아웃은 두 가지입니다.

  • 크롭 — 화면 일부만 남깁니다. 크롭 위치… 에서 현재 화면 위의 노란 창을 드래그해 남길 부분을 고르고, 위치는 영상마다 작업 파일에 저장됩니다. 얼굴캠·게임 화면 한 곳을 크게 보여 줄 때.
  • 블러 배경 — 16:9 화면 전체를 가운데 두고 위아래를 흐리게 확대한 같은 화면으로 채웁니다. 화면을 하나도 잘라 내고 싶지 않을 때.

항상 재인코딩이라 자르기 방식은 무시되고, GPU 인코더가 있으면 씁니다.

현재 화면 저장

Ctrl+P: 지금 보이는 프레임을 영상 옆에 이름_12m05s.png 로 저장합니다. 썸네일 만들 때 유용합니다.

URL 에서 열기

파일 ▸ URL 에서 열기 (Ctrl+L). 유튜브·치지직·트위치 VOD·아프리카 등 yt-dlp 가 지원하는 사이트의 주소를 넣으면 받아서 바로 목록에 추가합니다. 화질과 저장 폴더를 고를 수 있고 기본은 내 비디오\ClipSlicer 입니다. 받은 파일은 지우지 않습니다.

구간만 받기를 켜고 1:02:00 ~ 1:15:30 처럼 넣으면 그 부분만 받습니다. 몇 시간짜리 다시보기에 꼭 쓰세요 (전체는 수십 GB). 치지직 다시보기는 yt-dlp 가 아직 지원하지 못하는 형식이라 ClipSlicer 가 자체적으로 우회해서 받습니다.

로그인이 필요한 영상, 회원 전용 다시보기, DRM 영상은 받을 수 없습니다. 사이트가 바뀌면 yt-dlp 갱신이 필요할 수 있는데, 새 ClipSlicer 릴리스에 최신 버전이 포함됩니다.

유튜브 올리기

내보내기 패널의 완료 후 유튜브에 올리기를 켜면 내보내기가 끝날 때 올리기 창이 열립니다. 파일마다 제목·설명·태그·썸네일을 채우고 공개 범위·카테고리·재생목록을 골라 올리기. 이미 있는 파일은 파일 ▸ 유튜브에 올리기 (Ctrl+U).

로그인 정보는 Windows DPAPI 로 암호화해 프로그램 폴더의 youtube_token.bin 에 저장되고, 다른 PC 로 복사해도 열리지 않습니다 (다시 연결).

방송 북마크 모드

방송·녹화 중에 "이거 나중에 클립" 싶은 순간을 기록해 두는 기능입니다. 파일 ▸ 방송 북마크 모드… 를 열면 항상 위에 떠 있는 작은 창이 나오고, 그 뒤로는 전역 단축키(기본 Ctrl+Alt+B)를 누를 때마다 그 시각이 기록됩니다. OBS·게임·브라우저가 앞에 있어도 됩니다.

  1. 방송 전에 창 열기. 파일 ▸ 방송 북마크 모드…. 단축키는 Ctrl+Alt+B / Ctrl+Alt+M / Ctrl+Shift+B / F9 / F10 중 고를 수 있고, 다른 프로그램이 이미 쓰는 조합이면 알려 줍니다. 창의 ● 지금 북마크 버튼도 같은 일을 합니다. 기록될 때 짧은 소리가 납니다.
  2. 방송 중 단축키. 기록 시각이 창의 목록에 쌓입니다. 창을 닫으면 단축키도 해제됩니다.
  3. 녹화 파일 열기. 녹화가 끝난 파일을 ClipSlicer 에 열면, 그 녹화 시간대에 찍은 북마크가 있을 때 마커로 가져올까요? 하고 묻습니다. 나중에 하려면 편집 ▸ 북마크 가져오기…. 가져온 마커도 Ctrl+Z 로 되돌릴 수 있습니다.
시간 계산 방법 — 파일의 수정 시각을 녹화가 끝난 시각으로 보고, 영상 길이를 거슬러 올라가 "북마크 시각 → 영상 안의 위치"를 계산합니다. 녹화 프로그램이 만든 원본 파일을 바로 여는 게 가장 정확하고, 녹화 뒤에 복사·재인코딩해서 수정 시각이 바뀐 파일은 시간대가 어긋납니다.

기록은 프로그램 폴더의 bookmarks.jsonl 한 파일에 쌓이고(날짜·시각·메모), 창의 기록 지우기로 비웁니다. 전역 단축키는 Windows 에서만 동작합니다.

큰 소리 · 채팅 반응 마커

큰 소리에 자동 마커 (웃음 · 환호)

편집 ▸ 큰 소리에 자동 마커… (Ctrl+Shift+L). 이미 분석된 파형에서 평소 음량보다 유난히 큰 곳(웃음·고함·환호·효과음)을 찾아 마커를 넣습니다. 파형을 다시 읽지 않아 바로 끝납니다.

설정설명
기준 배율평소 음량(중앙값)의 몇 배를 넘어야 "큰 소리"로 볼지. 기본 3배. 낮출수록 많이 잡힙니다 (2~8).
마커 최소 간격이보다 가까운 큰 소리는 하나로 칩니다. 기본 10초.
앞당김마커를 큰 소리보다 이만큼 앞에 둡니다 (기본 2초). 클립이 반응 직전부터 시작하도록.

최대 50개까지, 시작점 하나만 찍힙니다. 각 마커 뒤에서 O 로 클립 끝을 정하거나 다음 마커까지를 구간으로 쓰세요. 결과는 Ctrl+Z 한 번으로 전부 되돌아갑니다.

채팅 반응 그래프 · 키워드 마커

편집 ▸ 채팅 반응 그래프·마커… (Ctrl+Shift+C). 치지직 다시보기(chzzk.naver.com/video/…) 또는 유튜브 라이브 다시보기 주소를 넣고 채팅 가져오기를 누르면 채팅을 받아 타임라인 썸네일 띠 아래에 주황색 반응 그래프를 그립니다. 그래프가 솟은 곳이 채팅이 쏟아진 순간입니다. URL 로 받은 영상은 주소가 미리 채워집니다.

옵션설명
반응 많은 곳에 마커채팅이 가장 많이 쏟아진 시간대를 최대 N곳(기본 20) 골라 마커. 최소 간격(기본 60초)보다 가까운 피크는 하나로.
키워드 반응 마커쉼표로 적은 말(ㅋㅋㅋ, 미쳤다, 클립, 레전드, ㄷㄷ)이 들어간 채팅만 세서 가장 많은 곳에 마커. 대소문자 구분 없고 이모지도 됩니다.
예상 마커창 아래에 두 종류를 합친 예상 개수가 미리 표시됩니다. 마커 추가를 누르면 넣습니다.

받은 채팅은 영상이름.clipslicer.chat.json 에 저장돼 다음에 같은 영상을 열면 그래프가 바로 그려지고 다시 받지 않아도 됩니다. 창을 취소해도 받은 채팅은 유지됩니다.

치지직은 다시보기 채팅이 공개된 영상, 유튜브는 라이브 방송 다시보기(채팅 다시보기가 있는 것)만 됩니다. 일반 업로드 영상의 댓글은 대상이 아닙니다. 서버 응답이 없으면 세 번까지 자동으로 다시 시도합니다.

메모

구간 목록의 메모 칸을 더블클릭하면 "여기 웃긴 부분", "광고 뒤 다시 확인" 같은 메모를 적을 수 있습니다. 파일명이나 내보내기에는 영향이 없고 작업 파일에 저장되며 실행 취소도 됩니다. 구간 이름은 더블클릭 외에 N(현재 재생 위치의 구간) · F2(목록에서 선택한 구간)로 바로 편집할 수 있습니다. 오른쪽 패널이 접혀 있으면 자동으로 펼쳐집니다.

합치기 순서

하나로 합치기를 켜면 구간 목록에 순서 칸이 나타납니다. 번호는 켜진 구간만 세고, 바꾸지 않으면 시간순입니다. ▲ ▼ 버튼(또는 Ctrl+Shift+↑ Ctrl+Shift+↓)으로 이어 붙일 순서를 바꾸면 "엔딩 장면을 맨 앞에 두는 하이라이트" 같은 구성이 됩니다. 순서는 작업 파일에 저장되고, 구간이 꺼지거나 지워지면 순서에서 자동으로 빠집니다.

출력 효과: 음량 · 캡션 · 자막 · 워터마크 · 인트로

옵션어디서설명
음량 정규화내보내기 패널loudnorm(-14 LUFS, 유튜브 기준)으로 소리 크기를 고르게 맞춥니다. 오디오만 AAC 192k 로 다시 인코딩하고 영상은 그대로 복사하므로 여전히 빠릅니다. 합칠 때는 마지막에 한 번만 적용됩니다.
캡션내보내기 패널적은 글자를 영상 아래쪽 가운데에 굽습니다 (흰 글자 · 검은 테두리 · 반투명 상자, 크기는 화면 높이의 약 5%). 클립마다 같은 문구가 들어가므로 채널 이름이나 "풀영상은 채널에" 같은 안내에 맞습니다. 그때그때 쓰는 값이라 다음 실행에는 비워집니다.
자막내보내기 패널원본 영상 기준의 .srt / .ass / .vtt 파일을 고르면 잘라낸 구간에 맞춰 시각을 옮긴 뒤 영상에 굽습니다.
워터마크설정 ▸ 워터마크 / 인트로·아웃트로…PNG 로고를 네 모서리 중 한 곳(여백 24px)에 원하는 불투명도로 얹습니다. 투명 배경 PNG 를 쓰세요.
인트로 · 아웃트로설정 ▸ 워터마크 / 인트로·아웃트로…영상을 앞·뒤에 붙입니다. 본편의 해상도·프레임률에 맞춰 변환되고 소리가 없으면 무음이 채워집니다. 재인코딩되는 출력에만 붙습니다.
재인코딩 규칙 — 캡션·자막·워터마크 중 하나라도 있으면 글자·그림을 영상에 새겨야 하므로 "빠르게"를 골라도 재인코딩됩니다 (출력 mp4, 로그에 표시, GPU 인코더 사용). 인트로/아웃트로는 정확하게 · 세로 · 캡션 · 자막 · 워터마크처럼 어차피 재인코딩되는 출력에만 붙고, 빠르게·스마트로 복사한 파일에는 붙지 않습니다. 음량 정규화만 켠 경우에는 영상 복사가 유지됩니다. 워터마크·인트로 설정은 모든 영상에 공통이며, 비워 두면 쓰지 않습니다.

유튜브 프리셋 · 예약 공개 · 업로드 이력

업로드 프리셋

올리기 창 맨 위의 프리셋 목록. 관리…에서 이름 · 제목 템플릿 · 설명 템플릿 · 태그 · 카테고리 · "#Shorts 붙이기"를 묶어 두면, 고르는 순간 창의 모든 항목에 한 번에 채워집니다. (프리셋 없음)을 고르면 원래 값으로 돌아가고, 마지막에 쓴 프리셋은 다음에 창을 열 때 자동으로 적용됩니다.

자리표시자뜻
{title}파일 이름 (구간 이름)
{source}원본 영상 이름
{start} {end}구간 시작 · 끝 시각
{n}구간 번호

템플릿을 비우면 그 항목은 바꾸지 않습니다 (제목은 파일 이름 그대로).

예약 공개

공통 설정의 예약 공개를 켜고 시각(내 컴퓨터 시간)을 고르면, 비공개로 올라간 뒤 그 시각에 유튜브가 자동으로 공개합니다. 공개 범위 선택은 비공개로 고정되고 지난 시각은 거부됩니다. 심사(검증)받지 않은 프로젝트에서는 예약이 무시되고 비공개로 남을 수 있습니다.

업로드 이력

파일 ▸ 업로드 이력…. 올린 날짜 · 제목 · 파일 · 링크 · 채널이 표로 남고, 링크 열기 · 링크 복사 · 스튜디오 열기(선택한 영상의 편집 페이지)가 됩니다. youtube_uploads.jsonl 에 저장되며 올리기 창에서도 열 수 있습니다.

디스코드로 보내기

  1. 웹훅 만들기. 디스코드에서 채널 설정 ▸ 연동 ▸ 웹훅 ▸ 새 웹훅 ▸ 웹훅 URL 복사.
  2. 등록. ClipSlicer 설정 ▸ 디스코드 웹훅… 에 URL 을 붙여넣고 테스트 메시지 보내기로 확인. 파일 크기 한도(10 / 25 / 50 / 100 MB)는 서버 부스트 단계에 맞춰 고르고, 메시지 템플릿에는 {title}(파일 이름) {source}(원본 이름)를 쓸 수 있습니다.
  3. 내보내기 패널의 "디스코드로 보내기" 켜기. 내보내기가 끝나면 잘린 파일들이 차례로 채널에 올라가고 로그에 ✔ / ✖ 가 표시됩니다.

한도를 넘는 파일은 보내지 않고 건너뛰며 로그에 알려 줍니다. 쇼츠 길이의 클립이면 대개 10 MB 안에 들어가고, 더 큰 클립은 "정확하게" 모드로 다시 뽑거나 서버 부스트가 필요합니다. 요청이 너무 잦으면(429) 잠시 기다렸다가 자동으로 다시 보냅니다.

시작 화면 · 알림 · 처음 사용 안내

기능설명
시작 화면영상이 하나도 없을 때 플레이어 자리에 나옵니다. 파일 열기 · URL 에서 열기 · 샘플 영상으로 둘러보기 버튼과 최근 작업 이어서 목록(최근 5개, 마커 수 · 켜진 구간 수와 함께). 빈 곳을 클릭해도 파일 열기.
샘플 영상ffmpeg 로 30초짜리 연습용 영상을 만들어 엽니다 (장면 전환 4곳 · 무음 3초 포함). 자동 마커 기능을 시험해 보기 좋습니다. 프로그램 폴더 samples\sample.mp4 에 남겨 두고 다시 씁니다.
처음 사용 안내첫 실행 때 세 단계(끌어다 놓기 → S · I/O → Ctrl+E) 안내 창이 뜹니다. "다시 보지 않기"가 기본으로 켜져 있고, 도움말 ▸ 처음 사용 안내… 로 언제든 다시 봅니다.
트레이 알림내보내기 · 다운로드 · 유튜브 업로드가 끝났을 때 ClipSlicer 가 뒤에 있거나 최소화돼 있으면 작업 표시줄 알림으로 알려 줍니다. 앞에 있을 때는 상태 표시줄 메시지만. 트레이 아이콘 메뉴에서 창 보이기 · 종료.

자동 저장 · 설정

작업 파일 (.clipslicer.json)

마커·구간 켜짐·직접 정한 이름·메모·합치기 순서·크롭 위치·원본 URL·마지막 재생 위치가 영상과 같은 폴더에 영상이름.mp4.clipslicer.json 으로 자동 저장됩니다 (변경 후 0.6초 뒤, 영상 전환 시, 종료 시). 같은 영상을 다시 열면 그대로 복원되고 상태 표시줄에 "저장된 작업 복원"이 표시됩니다. 이 json 파일을 창에 끌어다 놓아도 해당 영상이 열립니다. 영상을 다른 PC 로 옮길 때 같이 옮기면 작업이 유지됩니다.

저장할 때마다 직전 내용이 영상이름.mp4.clipslicer.json.bak 으로 남습니다. 실수로 마커를 다 지우고 저장됐다면 .bak 의 이름을 되돌려 복구할 수 있습니다. 채팅은 영상이름.mp4.clipslicer.chat.json, 분석 캐시는 .clipslicer.cache 에 따로 저장됩니다.

업데이트

시작할 때 GitHub 릴리스를 조회합니다(1시간에 한 번까지, 끌 수 있음). 새 버전이 있으면 오른쪽 아래에 ⬆ 새 버전 버튼이 뜨고, 지금 업데이트를 누르면 zip 다운로드 → SHA-256 검증 → 프로그램 종료 → 파일 교체(설정·로그·작업 파일 유지, 이전 버전은 _backup) → 재실행이 자동으로 진행됩니다. 교체에 실패하면 백업에서 되돌리고 알려 줍니다. 읽기 전용 위치(USB 쓰기 금지 등)에서는 다운로드 페이지만 안내합니다.

경량 업데이트 — 코드만 바뀐 릴리스는 번들된 ffmpeg · libmpv 를 그대로 두고 약 20 MB 짜리 경량 zip 만 받습니다 (업데이트 창에 "경량" 표시). ffmpeg 나 libmpv 가 바뀐 릴리스는 전체 zip 으로 받습니다. 어느 쪽인지는 릴리스의 deps.txt 와 설치된 버전을 비교해 자동으로 판단합니다.

문제 해결

증상원인과 해결
"빠르게"로 잘랐더니 앞부분이 길다정상입니다. 키프레임 때문입니다. 스마트 모드를 쓰거나 "마커를 키프레임에 맞추기"를 켜세요.
잘린 파일의 처음 1~2초가 깨져 보인다스마트 모드의 이음새를 일부 플레이어가 잘 못 다루는 경우입니다. "정확하게"로 다시 뽑으세요.
내보내기 실패 (로그에 ffmpeg 오류)출력 폴더 쓰기 권한, 디스크 공간, 또는 MKV 의 자막·첨부 스트림을 MP4 로 복사하려는 경우. 마지막 경우는 "정확하게" 모드 사용.
영상이 안 열린다 / 화면이 까맣다손상된 파일이나 DRM 파일은 안 됩니다. 화면만 까맣다면(원격 데스크톱·가상머신·구형 GPU) 설정 ▸ 호환 모드를 켜고 다시 실행하세요.
오류 창이 떴다"로그 폴더 열기"를 눌러 clipslicer.log 를 확인하세요. 모든 오류가 거기 남습니다. (도움말 ▸ 로그 폴더 열기)
썸네일·파형이 안 생긴다아주 긴 영상은 수십 초 걸립니다. 오디오가 없으면 파형이 없습니다. ffmpeg 가 PATH 나 bin 폴더에 있어야 합니다.
단축키가 안 먹는다구간 목록의 파일명을 편집 중이면 키가 그쪽으로 갑니다. Esc 로 편집을 끝내거나 플레이어를 한 번 클릭하세요.
무음 구간을 못 찾는다기준 음량을 올리거나(-25 dB), 최소 길이를 줄이세요. 배경음악이 깔린 영상은 무음이 없습니다.
GPU 인코더가 "없음"으로 나온다그래픽 드라이버가 오래됐거나 ffmpeg 빌드에 해당 인코더가 없는 경우입니다. CPU 로도 모든 기능이 동작합니다.
"필요한 파일이 없습니다" 창ffmpeg.exe ffprobe.exe libmpv-2.dll 이 프로그램 폴더(또는 bin)에 있어야 합니다. 아래 설치 항목 참고.
"빠르게"를 골랐는데 재인코딩됐다캡션·자막·워터마크 중 하나라도 있으면 영상에 새겨야 하므로 재인코딩됩니다. 캡션·자막 칸을 비우고 설정의 워터마크를 지우세요. 음량 정규화만으로는 재인코딩되지 않습니다.
북마크를 가져올 게 없다고 한다파일 수정 시각을 녹화 끝으로 보고 계산합니다. 녹화 뒤 복사·변환한 파일은 시간대가 어긋나니 녹화 프로그램이 만든 원본에서 가져오세요.
북마크 단축키가 등록되지 않는다다른 프로그램이 같은 전역 단축키를 씁니다. 북마크 창에서 다른 조합(F9, F10 등)을 고르세요. Windows 에서만 동작합니다.
채팅을 못 받는다치지직은 다시보기 채팅이 공개된 영상, 유튜브는 라이브 다시보기만 됩니다. 주소가 맞는데도 안 되면 잠시 뒤 다시 시도하세요.

설치 · 빌드

배포판 (exe)

dist\ClipSlicer\ 폴더를 통째로 원하는 곳(USB 포함)에 두고 ClipSlicer.exe 를 실행합니다. 설치 과정 없음, 설정은 폴더 안 settings.ini 에만 저장되는 포터블 구조입니다.

소스에서 실행

git clone https://github.com/vtubeadmirer/clipslicer
cd clipslicer
pip install -r requirements.txt
python tools\get_libmpv.py      # bin\libmpv-2.dll (7-Zip 또는 Bandizip 필요)
python tools\get_ffmpeg.py      # bin\ffmpeg\ 공유 빌드
python main.py

ffmpeg 는 tools\get_ffmpeg.py 가 버전을 고정해 받습니다. 없으면 PATH 의 ffmpeg 를 씁니다. 지원 환경: Windows 10 1809 이상 64비트.

exe 빌드

.\build.ps1        # PyInstaller → dist\ClipSlicer\ClipSlicer.exe
